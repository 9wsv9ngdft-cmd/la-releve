# La Relève — Console MJ

Jeu d'enquête en temps réel joué par messages. Le joueur reçoit des messages de « Léo », gardien de nuit coincé dans un sous-sol avec un intrus. Le MJ joue Léo depuis un vrai numéro (WhatsApp), et l'intrus écrit dans la même conversation.

Ce dépôt contient la **console du MJ** :

- **`index.html`** : la console (conducteur, énigmes et indices, réponses d'impro, médias, check-list de préparation).
- **`scenario.js`** : tous les textes du jeu. C'est le seul fichier à modifier pour changer l'histoire.
- **`medias/`** : les documents d'enquête à envoyer au joueur.

⚠️ La console contient toutes les solutions. Ne partage pas ce lien avec le joueur.

## Média à ajouter toi-même

Seule la photo de profil de Léo (`leo.jpg`) n'est pas dans le dépôt, parce qu'il est public. Mets-la directement comme photo WhatsApp du numéro de Léo.
